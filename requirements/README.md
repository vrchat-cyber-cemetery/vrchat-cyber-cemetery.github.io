# 赛博墓地需求文件夹

当前版本：**v0.5**，更新日期：**2026-10-03**。

目标是一个无自建常驻服务器、社区可接续维护和分叉的赛博墓地：支持绑定 VRChat 玩家，默认一次创建机会，并通过有效评审贡献获得更多创建次数。

## 阅读须知

- 用户明确了无自建服务器、去中心化方向、玩家绑定和“默认 1 次、评审换更多次数”的目标。
- 已确认一个共享的 VRChat 墓园世界容纳多位成员投稿的墓碑，访客可以浏览全部已发布内容，不引入个人墓园或每人独立世界。
- DEC-01～06已随实施计划确认：数字ID初始1次、可选绑定、3有效评审换1次，镜像不重新发放。
- 政策批准不代表功能上线，自动投稿和真实奖励保持关闭，等待后续实现与独立核验条件。
- 已确认优先GitHub和本社区额度分域，不依赖个人运营的长期后端；Fork不自动合并余额。
- 可以为他人和非 VRChat 人物／事物创建墓碑，发布后提供静态分享页；对本人同意、审核与撤下的要求保持一致。
- 本轮建立四仓库、配置和基础CI；Unity／后台治理验收仍未执行。

## 维护方式

主需求保留稳定 REQ 编号；治理文档细化规则并引用对应编号，评审报告记录问题与处理状态。修改政策时同步调整验收场景；已明确的目标与待确认建议不得混写。根目录的 [REQUIREMENTS.md](../REQUIREMENTS.md) 仅作为兼容入口。
